I frequently use **Google Drive**, ** Messenger**, and **GCash** because they make my daily tasks more convenient.
**Google Drive** is a **Software as a Service (SaaS)** application that uses the **Public Cloud** deployment model. It allows users to store, access, and share files online without installing or managing storage servers. I use Google Drive because it is easy to submit school projects, organize my files, and access them from any device with an internet connection. 
**Messenger** is also a **Software as a Service (SaaS)** application that runs on the **Public Cloud**. It provides instant messaging, voice calls, and video calls over the internet. I use Messenger because it is a simple and reliable way to communicate with my classmates, friends, and family, especially for school announcements and group discussions. 
**GCash** is another example of **Software as a Service (SaaS)**. Its deployment model is **Hybrid Cloud** because financial services often combine public cloud technologies with private infrastructure to improve security, compliance, and reliability while still providing online access to users. I use GCash because it makes it easy to transfer money, pay bills, and make cashless payments anytime. 
**Version control** is essential when working with cloud infrastructure because it records every change made to files, scripts, and configurations. This makes it easier to track updates, identify mistakes, and restore previous versions if needed. **Git** and **GitHub** help teams collaborate by allowing multiple developers to work on the same project without overwriting each other's work. Features such as branches, pull requests, and commit history improve teamwork, simplify code reviews, and reduce errors when managing cloud resources.
