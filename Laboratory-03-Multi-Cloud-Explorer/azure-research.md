**Brief Overview**

Microsoft Azure is a complete cloud computing service provided by Microsoft that consists of computing services, storage services, database services, networking, analysis, artificial intelligence, and application development. Through this platform, companies and software engineers can create and deploy their applications using Microsoft's worldwide infrastructure on both cloud and hybrid cloud. Furthermore, Microsoft offers Azure for students in which eligible university students get free Azure services along with $100 credit without using any credit card.

**Global Infrastructure**

Microsoft Azure offers a global network of geographies, regions, and availability zones to cater to data sovereignty and compliance requirements. Azure has more than 70 geographies announced globally, which allows the company to choose the most suitable regions to host its applications. Azure Availability Zones contain independent data centers located within a specific geography, and have distinct power, cooling, and networking facilities interconnected via low-latency networks.

**Cloud Management Console**

The Azure Portal is the web console offered by Microsoft for management of the Azure applications and resources. The portal allows you to manage VMs, databases, storage, network, and security together with monitoring options to control the cloud resources.

**Four (4) Core Services**

1.**Azure Virtual Machines**

Azure Virtual Machines offers scalable virtual machines where companies can run their applications and operating systems in the cloud. This service is suitable for workloads that need management of the computing environment.

2.**Azure Blob Storage**
Microsoft Azure Blob Storage is an object-based storage solution used for storing large volumes of unstructured data like pictures, videos, files, and documents.

3.**Azure SQL Database**

Microsoft Azure SQL Database is a relational database management system that uses Microsoft SQL Server as its foundation. It enables enterprises to utilize databases without managing a lot of the infrastructure involved.

4.**Azure Functions**

Azure Functions is a serverless computing platform that allows developers to execute their code in reaction to certain events without managing servers. Azure Functions are useful in event-driven applications, automation, APIs, and background processes. Azure provides a variety of products like Virtual Machines, Azure SQL, and storage solutions.

**Three (3) Advantages**

1.**Global Availability**

This is because Azure offers cloud-based infrastructure in various locations across the globe. This gives businesses the ability to deploy applications close to their customers and pick locations based on their needs.

2.**Scalability**

Azure permits the ability to scale up and down on computing, storage, and other services depending on the load. It becomes easier to manage variations in demand without needing to acquire any more hardware.

3.**High Availability and Reliability**

The Azure Availability Zones have physically separated data centers with their own power, networking, and cooling systems. Businesses can allocate workloads in different zones to enhance the availability of applications.

**Typical Enterprise Use Cases**

1.**Web and Application Hosting**

Companies use Azure Virtual Machines, Azure App Service, and various other Azure technologies to host their websites and business applications.

2.**Data Storage and Backup**

Document, image, video, back-up, and other types of information related to businesses are stored on Azure storage.

3.**Database Management**

Organizations utilize Azure SQL Database, along with various Azure database solutions, for handling databases for business applications, client systems, and transaction processing systems.

4.**Business Analytics and Data Processing**

Data and Analytics Services from Azure are used by enterprises for processing huge amount of data, creating reports and gaining insights for business decisions.

5.**Artificial Intelligence and Machine Learning**

Azure AI and Machine Learning Services help in creating smart applications and automating tasks through the process of analyzing data using artificial intelligence.
