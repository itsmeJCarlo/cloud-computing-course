**Brief Overview**
AWS Educate is an Amazon Web Services program that provides students and educators with the resources to learn about cloud computing and build hands-on cloud skills. Amazon Web Services (AWS) is a cloud computing platform that delivers on-demand services like computing, storage, databases, networking, security, and application development. It provides learning resources and opportunities for learners to explore AWS technologies without needing extensive prior cloud experience. Instead of keeping their own physical servers, users can access these resources over the Internet.
**Global Infrastructure**
The AWS global cloud infrastructure includes Regions, Availability Zones, Local Zones and Wavelength Zones. A Region is a separate geographical area with multiple isolated Availability Zones, which are separate data centers connected with high bandwidth low latency links. This setup increases the availability and fault tolerance of the application. Also, Local Zones bring some AWS resources closer to end users, benefiting applications that require low network latency.
**Cloud Management Console**
The AWS Management Console is a web-based interface that enables users to manage AWS services by creating, configuring, and monitoring cloud resources without using the command line. It enables actions such as launching Amazon EC2 instances, creating S3 buckets, configuring databases, managing permissions, and monitoring resources. AWS Global View also gives you a view of resources across multiple AWS Regions.
**Four (4) Core Services**
1. **Amazon EC2 (Elastic Compute Cloud)**
 Amazon EC2 provides virtual servers, called instances, to run your applications and workloads in the cloud. You can choose from many different hardware resource configurations to meet your computing needs.
2.**Amazon S3 (Simple Storage Service)**
  You can use Amazon S3, an object storage service, to store and retrieve files and other types of data. You can use it for documents, images, videos, backups and application data.
3.**Amazon RDS (Relational Database Service)**
  Amazon RDS is a relational database management system that allows users to build, control, and manage their databases with little involvement in the internal processes of managing the database system.
4.**AWS Lambda**
  It is a serverless computing platform by AWS that lets users deploy their code on AWS servers. The applications are able to perform functions in response to certain events.
**Three (3) Advantages**
1.**Scalability**
   AWS enables the user to scale up and down cloud computing resources according to the demand of workload. Due to which the application can adapt itself to the changing number of users and workload without buying more physical servers.
   2.**Global Availability**
   In addition, AWS has its infrastructure in multiple geographical locations across the globe. In this regard, companies are able to choose Regions that are closest to their users in order to achieve certain objectives.
   3.**High Availability and Fault Tolerance**
   Multi-AZ implementation in AWS ensures that applications and their resources can be spread across different physical locations. In case there is a problem with one Availability Zone, applications designed for multi Availability Zones can continue running at another location.
**Typical Enterprise Use Cases**
1.**Website and App Hosting**
   This is a use case where enterprises use AWS to host websites, mobile apps, and business systems without having to own any physical services.
2.**Storage and Backing Up**
   Companies make use of AWS services like Amazon S3 to store their documents, databases, backups, and other essential business data.
3.**Database Operations**
   Through the AWS service known as Amazon RDS, companies are able to run their databases of applications, customer records, transactions, and more.
4.**Big Data and Data Analysis**
   Using AWS, organizations can analyze and process large amounts of data to help with decision making and discovering trends.
5.**Disaster Recovery**
   Through AWS, companies are able to keep backups and recoveries of their systems in order to restore applications and data when their primary systems fail or get disrupted.
