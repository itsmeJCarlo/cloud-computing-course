Client A – Startup Company
A startup company wants to launch a new mobile application. Their budget is limited, but they expect rapid growth within the next few years.

It is advisable to use AWS since it has numerous services that will be able to scale according to the growth of the startup mobile application. In addition, it will also have various payment plans that will enable the company to start by having fewer resources and adding more according to the increase in demands.

**Three Services**

**Amazon EC2** - To run the backend server of the application.
**Amazon S3** - For keeping images and files of the application.
**Amazon RDS** - For managing the relational database of the application.

Client B – University
A university already uses:
●Windows Server 
●Microsoft 365 
●Active Directory 
The university wants to migrate some services to the cloud.

I suggest going with Microsoft Azure as it is compatible with all other Microsoft technology that is used at the university. Azure is able to interact with Windows Server, Microsoft 365, and Active Directory which will make the cloud migration process more convenient for the university.

**Three Services**

**Azure Virtual Machines** – for migrating and running Windows Server workloads. 
**Microsoft Entra ID** – for identity and access management and integration with existing Active Directory. 
**Azure Storage** – for storing university documents, files, backups, and other data.


Client C – AI Research Company
A research company develops Artificial Intelligence and Machine Learning applications that require high-performance computing.

Because Google Cloud offers high-performance computing resources for demanding workloads and has strong AI and machine learning capabilities, it is advised. It provides specialized infrastructure, such as GPUs and TPUs, that can speed up the development and training of AI models. Additionally, Google Cloud offers services and tools that assist researchers in developing, refining, and implementing machine learning applications.

**Three Services**

**Google Compute Engine** – for high-performance virtual machines and GPU-based computing. 
**Vertex AI** – for building, training, deploying, and managing machine learning models. 
**Google Kubernetes Engine (GKE)** – for running and scaling containerized AI/ML workloads.

Client D – Global E-Commerce Company
A multinational online shopping company serves customers around the world and requires highly available infrastructure with automatic scaling.

AWS is recommended because it has a large global infrastructure that can support an e-commerce platform serving customers around the world. Its scalable services can automatically adjust resources based on traffic, while multiple Availability Zones can help maintain high availability. AWS also provides a wide range of services for hosting, databases, storage, and content delivery.

**Three Services**

**Amazon EC2 / Auto Scaling** – to automatically increase or decrease computing resources based on demand. 
**Amazon RDS** – for managing the company's relational database. 
**Amazon CloudFront** – to quickly deliver website content to customers around the world.
